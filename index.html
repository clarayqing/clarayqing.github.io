ideal-gas law.

Physics-aware symbolic correction for CO₂

I used symbolic regression with PySR to learn how much the ideal-gas law needs to be corrected for CO₂ at different temperatures and densities. The model blends equations fitted to CoolProp reference data to predict pressure across those conditions.

Domain & evaluation notes +

The natural grid covers 310–500 K and molar densities of 100–20,000 mol/m³. Complete temperature isotherms are held out for validation and testing.

The stress test uses a denser grid within that domain to check how the model handles a shift toward higher densities. The final model’s maximum pointwise pressure errors are 9.064% on the natural test and 5.186% on the stress test.

C++ notebook

Count subarrays with a target sum

How many contiguous slices of [2, -2, 3, 0] add up to 3?

Show the reasoning and C++ solution +

Four slices add up to 3. Both [2, -2, 3] and [3] qualify, and appending the final zero to either gives two more.

If the current prefix sum is s, every earlier prefix sum equal to s − target marks the start of a valid slice. Count matches before recording s to exclude empty slices. Include a starting sum of zero for slices that begin at the first element.

The hash map gives expected O(n) time and O(n) space.

#include <unordered_map>
#include <vector>

long long count_subarrays(const std::vector<int>& values, int target) {
    std::unordered_map<long long, long long> frequency{{0, 1}};
    long long prefix = 0;
    long long count = 0;

    for (int value : values) {
        prefix += value;
        auto match = frequency.find(prefix - target);
        if (match != frequency.end()) {
            count += match->second;
        }
        ++frequency[prefix];
    }

    return count;
}
